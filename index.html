카카오맵 API 설정

카카오디벨로퍼스의 JavaScript 키를 입력해. REST API 키/어드민 키는 입력하면 안 돼. 브라우저 공개 키이므로 도메인 등록과 사용량 제한을 설정해 줘.

JavaScript 키

카카오디벨로퍼스 앱 설정에서 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인에 https://affossoffa.github.io를 등록해야 해. 등록한 앱의 카카오맵 사용 설정/권한도 확인해 줘.

키는 파일이나 GitHub에 저장되지 않고 현재 브라우저에서만 사용돼. 새로고침하면 다시 연결해야 해.

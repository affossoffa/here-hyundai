# 🚗 여기가 딱이긴 현대

**각자 출발해도, 만날 곳은 공평하게.**

「여기가 딱이긴 현대」는 서로 다른 위치에서 자동차로 출발하는 여러 사람이 이동 시간을 비교하고, 모두에게 공평한 중간지점과 주변 핫플레이스를 찾아 함께 목적지를 결정할 수 있도록 돕는 차량 특화 소셜 모빌리티 서비스입니다.

2026 현대자동차그룹 차량용 앱 개발 공모전 출품을 위해 제작한 웹 프로토타입(v1.1)으로, 현재 핵심 기능을 목데이터 기반으로 시연할 수 있으며 향후 Pleos Connect를 활용한 차량용 애플리케이션으로 발전시킬 계획입니다.

## 💡 기획 배경

친구나 지인들이 각자의 자동차를 이용해 만날 때, 서로 다른 출발 위치로 인해 모두에게 공평한 약속 장소를 결정하기 어렵다는 문제가 있습니다.

기존 지도 서비스에서는 각자의 이동 시간을 일일이 비교해야 하며, 지리적 중간지점이 실제 주행 시간상 최적의 장소는 아닐 수 있습니다.

이에 실제 자동차 이동 시간을 기반으로 공평한 중간지점과 주변 핫플레이스를 추천하고, 친구들과 함께 목적지를 결정할 수 있는 서비스를 기획하였습니다.

## ✨ 주요 기능

### 1. 다중 출발지 기반 중간지점 시각화

- 여러 참가자의 출발 위치를 지도에 표시
- 각 출발지를 연결한 다각형 시각화
- 후보 장소를 지도 마커로 표시
- 지도에서 장소 선택 시 상세정보 제공

현재는 김포, 인천, 수원에서 출발하는 3명의 가상 참가자를 사용한 시연용 지도를 제공합니다.

### 2. 자동차 이동 시간 기반 장소 추천

- 참가자별 예상 자동차 이동 시간 비교
- 평균 이동 시간 및 최대 이동 시간 계산
- 참가자 간 이동 시간 차이 표시
- 추천 기준에 따라 후보 장소 정렬

**추천 기준**

- 공평한 만남: 가장 오래 이동하는 참가자의 이동 시간 최소화
- 빠른 만남: 모든 참가자의 이동 시간 합계 최소화
- 균형 있는 만남: 참가자 간 이동 시간 차이 최소화

현재는 목데이터를 기반으로 추천 로직을 시연하고 있으며, 향후 실제 자동차 경로 탐색 API를 연동할 예정입니다.

### 3. 핫플레이스 추천 및 비교

추천 지역 주변의 카페, 음식점, 문화시설 등 다양한 장소를 후보로 제공합니다.

지도에서 장소를 선택하면 오른쪽 상세정보 패널에 장소 유형과 참가자별 예상 이동 시간이 표시됩니다.

### 4. 핑(Ping) 및 장소 투표

게임에서 핑을 찍듯 친구들이 관심 있는 장소를 지도에 표시하고, 다른 참가자가 해당 장소를 선택할 수 있도록 설계했습니다.

- 친구가 선택한 장소 확인
- 친구의 선택 따라가기
- 원하는 장소에 직접 투표하기
- 장소별 투표 결과 확인
- 최종 목적지 선택

현재 친구의 핑은 시연용 데이터이며, 투표는 브라우저의 localStorage를 사용합니다. 여러 사용자가 실시간으로 투표하는 기능은 향후 Supabase와 연동할 계획입니다.

## 📍 핫플레이스 선정 기준 및 데이터 활용 계획

### 초기 데이터 확보 계획

핫플레이스 후보 장소는 우선 **공공데이터포털(https://www.data.go.kr/)**에서 제공하는 관광지, 음식점, 카페, 문화시설 등의 공공데이터를 활용하여 구축할 계획입니다.

공공데이터를 통해 장소명, 주소, 위치 좌표, 시설 유형 등의 정보를 확보하고, 여러 참가자가 자동차로 접근하기 편리한 지역을 중심으로 추천 후보를 선정하고자 합니다.

초기 추천에는 다음 기준을 적용할 계획입니다.

1. **접근성:** 각 참가자의 출발지에서 목적지까지 예상 자동차 이동 시간
2. **공평성:** 특정 참가자에게 이동 부담이 집중되지 않는 정도
3. **장소 유형:** 카페, 음식점, 문화시설 등 모임 목적과의 적합성
4. **데이터 신뢰성:** 장소 위치 및 운영 정보의 정확성

### 향후 추천 기준 고도화

공공데이터만으로는 실제 장소의 인기나 최신 트렌드를 충분히 반영하기 어렵다는 한계가 있습니다.

따라서 추후에는 다양한 장소 정보와 이용자 피드백을 결합하여 **핫플레이스 선정 기준을 지속적으로 보완할 계획**입니다.

특히 다음 요소를 추가로 고려하고자 합니다.

- 실제 방문자 평가 및 장소 인기도
- 최근 인기 장소와 지역별 트렌드
- 이용자의 관심사 및 선호 장소 유형
- 주차장 위치와 주차 편의성
- 전기차 충전시설 접근성
- 장소 운영시간 및 영업 여부
- 날씨와 교통 상황을 고려한 추천

이를 통해 단순히 자동차로 이동하기 편한 중간지점을 찾는 것을 넘어, 참가자들이 실제로 방문하고 싶은 장소를 추천하는 서비스로 발전시키고자 합니다.

**현재 프로토타입은 가상의 후보 장소와 이동 시간 데이터를 사용하며, 공공데이터포털 API 연동과 고도화된 핫플레이스 추천은 향후 개발 예정입니다.**

## 🛠️ 기술 스택

| 구분 | 기술 |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Database | Supabase (PostgreSQL) |
| 배포 | GitHub Pages |
| 시연 데이터 | Mock Data |
| 브라우저 상태 저장 | localStorage |
| 향후 사용자 인증 | Supabase Auth |
| 향후 실시간 동기화 | Supabase Realtime |
| 향후 차량용 앱 | Kotlin, Android |
| 향후 차량 연동 | Pleos Connect, NaviHelper SDK |

현재 Supabase에는 시연용 모임 및 장소 데이터를 저장했으며, 웹 프로토타입에 데이터 조회 코드를 구현했습니다. 데이터베이스 연결에 실패하는 경우에도 내장 목데이터로 시연할 수 있도록 구성했습니다.

## ▶️ 실행 방법

1. 웹 프로토타입 주소에 접속합니다.
2. 지도에서 참가자들의 출발 위치와 추천 후보 장소를 확인합니다.
3. 원하는 장소의 마커를 클릭합니다.
4. 오른쪽 상세정보 패널에서 참가자별 이동 시간을 비교합니다.
5. 친구의 핑을 따라가거나 원하는 장소에 직접 투표합니다.
6. 추천 기준을 변경하며 후보 장소의 순위를 비교합니다.

현재 웹 프로토타입은 별도의 APK 설치 없이 브라우저에서 실행할 수 있습니다.

## 🚀 향후 개발 계획

**회원가입 및 로그인**

- Supabase Auth를 활용한 회원가입 및 로그인
- 사용자별 프로필 생성 및 관리
- 사용자별 모임 기록 저장
- 계정 인증 및 접근 권한 관리

**친구 추가 기능**

- 사용자 검색 및 친구 추가

- 친구 목록 관리
- 친구에게 모임 초대 보내기

### 2단계. 그룹 생성 및 모임 관리

**그룹 만들기**

- 자주 만나는 친구들끼리 그룹 생성
- 그룹 이름 및 구성원 관리
- 친구 초대 및 그룹 참여
- 기존 그룹을 활용한 새로운 모임 생성

**모임 관리**

- 모임별 고유 초대 코드 생성
- 초대 링크로 모임 참여
- 참가자의 출발지 등록
- 모임별 후보 장소 관리
- 이전 모임 기록 확인

그룹 기능을 통해 매번 친구를 초대하거나 출발지를 새로 입력해야 하는 불편을 줄이고, 지속적으로 이용할 수 있는 서비스로 발전시킬 계획입니다.

### 3단계. 실시간 공동 의사결정

- Supabase Realtime 기반 실시간 데이터 동기화
- 참가자별 장소 핑(Ping) 공유
- 친구가 선택한 장소 따라가기
- 실시간 장소 투표 및 결과 반영
- 중복 투표 방지 및 투표 변경
- 최종 목적지 확정 및 공유

현재 브라우저에서만 동작하는 투표 기능을 실제 다중 사용자 서비스로 확장할 계획입니다.

### 4단계. 중간지점 및 핫플레이스 추천 고도화

- 공공데이터포털 API 연동
- 실제 장소 데이터 수집 및 정제
- 자동차 경로 탐색 API를 통한 이동 시간 계산

- 사용자 선호도 기반 장소 추천

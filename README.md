# 여기가 딱이긴 현대 — 1차 웹 프로토타입

자동차 이동 시간을 고려한 N명 모임 중간지점·핫플레이스 추천 및 장소 투표 서비스.

## 실행
`index.html`을 Chrome 또는 Edge로 열면 실행됩니다. 서버나 API 키가 필요하지 않습니다.

## 구현된 것
- 출발 도시 목록에서 참가자 등록/삭제 (2~8명)
- 출발지를 연결한 영역과 추천 후보 SVG 지도 개념도
- 가상 이동 시간에 대한 3가지 추천 기준: 최장 시간 최소 / 총 시간 최소 / 절충
- 장소별 참가자 이동 시간 비교
- 페이지 내 참가자별 1표 투표 (다시 투표하면 덮어씀)

## 아직 구현되지 않은 것 (중요)
- 실제 지도 타일, 실제 도로 경로/이동 시간, 실제 핫플레이스 데이터
- 다중 기기 실시간 연결, 계정 및 서버, 출발지 자동 위치 수집
- Pleos SDK, 차량 내비게이션 연동, 차량 환경에서의 실행 및 APK

현재 UI의 좌표와 시간은 모두 **임의 시연 데이터**이며, 실제 차량 주행을 위한 결정에 사용하면 안 됩니다.

## 다음 개발 단계
1. Android Studio Kotlin/AAOS 기본 프로젝트 생성 (minSdk 28+, API 34)
2. Pleos Connect Emulator 실행 및 권한/SDK 접근 확인
3. 지도 API 선택 및 실제 이동 시간 API 서버 연동
4. 모임 데이터 Firebase 등으로 온라인 동기화
5. FusedLocation, NaviHelper SDK 연동 및 주행 중 제한 UI 구현

공식 참고: https://document.pleos.ai/en/docs/pleos-only/getting-started
